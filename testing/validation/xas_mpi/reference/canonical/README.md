# Canonical JURECA reference

These x/y/z Fe L3 XAS spectra are the canonical acceptance reference for this
MPI ownership validation. They were generated by the approved clean JURECA
`np1` run from commit
`b3818dad42aa56fa3a835a9cf8e972e23ea2dd87` with one MPI rank, one OpenMP
thread, and `-pe_per_kpt 1`.

The files are:

- `xas_mpi_L3_x_eta0p030.dat`
- `xas_mpi_L3_y_eta0p030.dat`
- `xas_mpi_L3_z_eta0p030.dat`

`SHA256SUMS` records their approved checksums. Detailed executable, input,
restart, module, linkage, launcher, and job provenance is stored in
`../../provenance/clean_jureca_manifest.json`.
